# Demostración

La app funcionando, con los datos de una persona que no existe. Puedes tocar
todo: añadir un gasto, borrarlo deslizando una fila, cambiar los colores,
mirar los gráficos. **Al recargar vuelve a empezar**, porque no se guarda
nada: por debajo no hay ninguna base de datos, solo una de mentira que vive
en la memoria del navegador.

Abajo a la derecha hay un botón, **Ver la visita guiada**, que lo enseña todo
solo en poco más de un minuto.

Esta carpeta está generada. No se edita a mano:

```sh
node herramientas/construir-demo-publico.mjs
```
